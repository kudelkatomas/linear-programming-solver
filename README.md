# LP-Solver (Linear Programming Simplex Solver)

A Haskell implementation of the Simplex algorithm designed to solve the standard maximization problem in Linear Programming. The program accepts integer-based instances and computes exact solutions using rational numbers (Haskell's **Rational**) to avoid any floating-point rounding errors.

> **Note**: This project was developed to practice Haskell.

---

## Features

* **Exact Computations**: Utilizing Haskell's `Rational` data type for fraction-based, error-free arithmetic.
* **Bland's Rule**: Implements Bland's anti-cycling rule during pivot selection to prevent infinite looping.
* **Flexible Input Parsing**: Custom parser built using Parsec supporting both formatted and compact plain-text inputs.
* **Verbose Mode**: Optional flag to output the final tableau (matrix) for each solved instance.

---

## Project Structure

The codebase is structured under the `LPSolver` module hierarchy:

* `Main.hs`: CLI entry point, argument parsing, handling standard input/output streams, and orchestrating execution.
* `LPSolver/Parser.hs`: Text parsing components for deserializing vectors, matrices, and instances via Parsec.
* `LPSolver/Simplex.hs`: The core algorithm matrix operations, pivoting logic (`pivotLoop`), and finding the initial feasible solution (`initSimplexAndSolve`).
* `LPSolver/Types.hs`: Central data structures (`LPInstance`, `SimplexStatus`, `SimplexState`) and error handling definitions (`SimplexError`).

## Usage

Run the compiled binary via Cabal using the following syntax:
```bash
cabal run lp-solver -- [OPTIONS] [ARGUMENTS]
```

### Options

* `-h, --help` : Show the help message and exit.
* `-v, --verbose` : Print the final tableau (matrix) for every result.

### Execution Examples

Passing arguments directly via the command line:
```bash
cabal run lp-solver -- "{[[-3, 81],[93, 21]],[72, 56],[39, 20]}" ... "{...}"
```

> **Note**: The sample instance shown above was generated using the included `test_case_generator.py` script.

Piping an input file through standard input (Recommended):
```bash
cat input.txt | cabal run lp-solver
```

Piping input and saving the verbose outputs:
```bash
cat input.txt | cabal run lp-solver -- -v > output.txt
```

## Input File Format

Input files can contain multiple linear programming instances. Each instance must be enclosed in curly braces {} containing three comma-separated elements:

1. **Matrix A**: (list of lists representing rows)
2. **Vector b**: (list of constraints)
3. **Vector c**: (list of coefficients for the objective function)


You can format them using whitespace/newlines for readability, or write them compactly:

```text
{
    [
        [-3, 81],
        [93, 21]
    ],
    [72, 56],
    [39, 20]
}

{[[-3, 81],[93, 21]],[72, 56],[39, 20]}
```

## Technical Specifications & Current Limitations
* **Standard Maximization Focus**: The tool directly maximizes $c^T x$ subject to $Ax \le b$ and $x \ge 0$.

* **Status Flags**: Evaluation yields one of four outcomes: Running, Infeasible, Feasible Unbounded, or Optimal (which returns the solution vector, with its final component being the objective function value).

* **Known Limitations**: While initSimplexAndSolve handles basic transformation scenarios, certain edge cases (such as when the artificial variable $x_0$ remains in the basis) raise a NotImplemented error.
